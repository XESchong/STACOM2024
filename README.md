# STACOM2024
This is the repo for the STACOM 2024 paper "Improved 3D Whole Heart Geometry from Sparse CMR Slices".

For the toy case, we generate synthetic DICOM files (SAXs + LAXs) based on the dense segmentation, where the header information of each DICOM file is using template from Sunnybrook Cardiac Data (https://www.cardiacatlas.org/sunnybrook-cardiac-data/).
